One line of weather forecast, 140 characters at most, for a city that does
not exist — written to charm a bored commuter on the way to work.

**Entry (120 characters):**

> In Crumbletown, light rain, heavy gossip, and a 40% chance the 8:15 actually stops; bring an umbrella and a good excuse.

`main.ts` (Node stdlib only) validates the gate — a single line of 1 to 140
characters, not only white space, naming the invented city — and writes the
line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) with
no trailing newline.

Run it:

```sh
node main.ts
```
